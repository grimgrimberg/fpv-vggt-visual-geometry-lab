# Milestone 1: Synthetic And Mocked Core

## Goal

Build the first testable Python package slice without real media, real dataset
ingestion, real VGGT inference, cloud GPU use, or dashboard work.

## In Scope

- Python package skeleton.
- Typer CLI with `fpv --help`.
- Pydantic config and data schemas.
- Synthetic video generation for tests and demos.
- Deterministic frame extraction from synthetic videos.
- Frame quality metrics.
- Mocked VGGT output bundle creation and import.
- Pose filtering on mocked data.
- Conservative scale-free path-feature extraction on mocked data.
- Reconstruction summary JSON.
- `fpv run --synthetic` debug run folder.
- Pytest suite.

## Out Of Scope

- Real dataset catalog ingestion.
- Real media download.
- Real segment proposal for dataset videos.
- Real VGGT dependency.
- Hugging Face, Colab, or RunPod integration.
- Dashboard or polished final review HTML.
- ML training.
- TTVE modeling.
- Geolocation, map views, physical speed, standoff distance, dive angle, target
  analysis, or tactical recommendations.

## File-By-File Plan

- `pyproject.toml`: package metadata, dependencies, CLI entry point.
- `src/fpv_vggt_lab/__init__.py`: package version.
- `src/fpv_vggt_lab/cli.py`: Typer commands.
- `src/fpv_vggt_lab/schemas.py`: Pydantic models for frames, bundles, and summaries.
- `src/fpv_vggt_lab/synthetic.py`: synthetic video creation.
- `src/fpv_vggt_lab/frames.py`: deterministic frame extraction and quality metrics.
- `src/fpv_vggt_lab/vggt.py`: mocked bundle writer and bundle loader/validator.
- `src/fpv_vggt_lab/geometry.py`: pose filtering and scale-free descriptors.
- `src/fpv_vggt_lab/pipeline.py`: synthetic orchestrator and run-folder logging.
- `tests/`: behavior tests using only synthetic media and mocked VGGT.

## Test Plan

- `fpv --help` exits successfully.
- Synthetic videos can be generated.
- Synthetic videos can be deterministically sampled.
- Frame manifests include frame index, timestamp, path, dimensions, and quality.
- Mock VGGT bundles validate and align to sampled frames.
- Malformed bundles fail clearly.
- Reconstruction summaries include reliability, flags, and conservative descriptors.
- `fpv run --synthetic` creates `run.log`, `summary.json`, `NEXT_STEPS.md`, and artifacts.

## Acceptance Criteria

- `pytest` passes.
- `fpv --help` works.
- The synthetic end-to-end command produces a run folder.
- No command downloads real media.
- No command requires VGGT, CUDA, Hugging Face, Colab, or RunPod.
- README commands match the implemented CLI.

## Commands

```powershell
python -m pip install -e ".[dev]"
fpv --help
fpv run --synthetic --workdir .tmp/run-demo
pytest
```

## Risks And Simplifications

- OpenCV is used for local synthetic video and frame IO in Milestone 1.
- Frame sampling is fixed-count, not FPS-based.
- Reconstruction reliability is intentionally simple and transparent.
- Bundle schema may evolve when real Hugging Face exports are converted.
