# ADR-001: Project Scope

Date: 2026-06-22

## Status

Accepted

## Context

The project analyzes already-published FPV footage with visual-geometry tools.
The same inputs could be misread as operational drone-analysis material if the
scope is not explicit.

## Decision

The project is limited to offline historical-media review, relative VGGT-frame
geometry, reconstruction diagnostics, and conservative scale-free descriptors.
V1 excludes ML training and keeps TTVE as future-only retrospective research.

## Consequences

The project can build useful reconstruction review artifacts while avoiding
geolocation, guidance, maneuver prediction, physical speed claims, and tactical
recommendations.
